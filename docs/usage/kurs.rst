Nachdem der Kurs generiert wurde, erhalten die Schülerinnen eine
Hintergrundgeschichte zur Datenbank (**a**). Darunter ist die aktuelle Aufgabe
zu finden (**b**). Im großen Freitextfeld (**c**) können die Schülerinnen einem
SQL-Prompt eingeben, um die Aufgabe zu lösen. Mit „Antwort überprüfen“ (**d**)
erhalten die Schülerinnen Rückmeldung, ob die Antwort korrekt ist (**e**). Bei
Ausführungsfehlern wird die SQL-Fehlermeldung direkt angezeigt, sodass die
Schülerinnen anhand dieser ihre Fehler korrigieren können. Wenn der Prompt
ausführbar ist, wird den Schülerinnen das resultierende Ergebnis angezeigt
(**f**). Mit „Nächste Aufgabe“ (**g**) erhalten die Schülerinnen die nächste
Aufgabe. Sobald die letzte Aufgabe angezeigt wird, werden die Schülerinnen mit
„Kurs abschließen“ (**h**) zur :doc:`/usage/kurswahl` zurückgeleitet. Unter den
Aufgaben sind die Tabellen der Datenbank dargestellt (**i**) und können
aufgeklappt werden, um die Attribute zu sehen.

.. attention::

    Es kann vorkommen, dass die Aufgaben nicht eindeutig bzw. falsch formuliert
    sind. Die resultierende Tabelle muss, damit die Lösung als korrekt markiert
    wird, immer identisch mit der Musterlösung sein (inklusive Tabellennamen
    und Reihenfolge). Wenn dabei bereits zwischen Musterlösung und
    Aufgabenstellung eine Diskrepanz besteht, kann die Aufgabe trotz richtiger
    Lösung in einzelnen Fällen als Falsch markiert sein. Deshalb sollten bei
    unklaren Fällen immer Personen darüber entscheiden, ob die Aufgabe korrekt
    gelöst wurde.
