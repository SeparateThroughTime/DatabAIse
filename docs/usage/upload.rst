Upload der Datenbank
====================

.. note::

    Diese Seite ist nur für die Experimentalgruppe einsehbar.

.. image:: /images/usage/06Upload.png
    :align: center
    :width: 1200

Hier können die Schülerinnen bereits erstellte Datenbanken mit dem +-Symbol
(**a**) hochladen und mit "Zur Kurswahl" (**b**) mit diesen die Kurse
bearbeiten.

.. attention::

    Es können nicht beliebige Datenbanken hochgeladen werden. Die von der
    Software erstellten .sql-Dateien haben eine spezifische Struktur.
    Abweichungen können zu Fehlern in der Software führen. Zukünftige Updates
    werden möglicherweise daran arbeiten, dass alle Datenbanken in der Software
    genutzt werden können.
