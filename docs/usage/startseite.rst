Startseite
==========

Die Startseite enthält einen kurzen Anleitungstext (**a**) und mehrere Button.
Mit „Teilnahme an der Vorumfrage“ (**b**) und „Teilnahme an der Nachumfrage“
(**c**) werden die Schülerinnen auf eine externe Seite für den Pre- bzw.
Posttest geleitet. Im Normalbetrieb werden die Schülerinnen damit beginnen mit
„Erstelle Datenbank“ (**d**) zur :doc:`/usage/themenwahl` weitergeleitet zu
werden. Falls das nicht  die erste Stunde für die Schülerinnen ist und sie
bereits eine oder mehrere Datenbanken erstellt hat ist oder eine bestimmte
Datenbank(-auswahl) von der Lehrkraft zur Verfügung gestellt wurde, kommen sie
mit „Lade Datenbank hoch“ (**e**) zu einem Menü, in dem sie Datenbanken
hochladen können (**6**).
