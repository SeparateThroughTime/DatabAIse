Generelles
==========

DatabAIse ist eine Lernsoftware für das Thema Datenbanken im
Informatik-Unterricht. In dieser erstellen die Schülerinnen mithilfe von
generativer KI Datenbanken zu Themen ihrer Wahl und erhalten dann Aufgaben
dazu. Die Aufgaben sind in mehrere Kurse unterteilt, die bestimmte
SQL-Konzepte zum Schwerpunkt haben.

Für die Studie gibt es neben der eigentlichen Software noch eine Anwendung,
bei der für jeden Kurs eine feste Datenbank zugewiesen ist. Die Software der
Experimentalgruppe ist unter WEBSITE/a und die Software der Kontrollgruppe
unter WEBSITE/b zu erreichen. Im Folgenden werden die einzelnen Bereiche der
Anwendung erklärt.
